# VIE-Translate

A browser extension that translates video subtitles into natural,
context-aware Vietnamese using an LLM.

## Planned features
- Translate subtitles on YouTube and other web players
- Genre and tone aware translation (anh/em/tôi/bạn/chú/bác)
- Custom font, size, outline, and draggable position
- Dual-subtitle mode (original and Vietnamese)
- Whisper speech-to-text fallback for videos with no subtitles
